# web-ad-ctr-prediction-project
웹 광고 클릭률 예측 AI 경진대회 (데이콘 상위 2.5%)
## 프로젝트 설명
- 광고 클릭률을 예측하는 AI 모델 개발
- 7일간의 웹 로그를 기반으로 하루 동안의 광고 클릭률을 예측하는 AI 알고리즘 개발
- 데이터 파일 크기 : 2.76 GB
## 성과
- 순위: 29등 / 1,146팀
- 상위: 2.5%
- 점수: AUC 0.78026
## 사용 기술
- Python
- LightGBM
- XGBoost
- Pandas
## 파일 설명
- `EDA.ipynb`: 데이터 분석
- `modeling.ipynb`: 모델링
